La signature — le halo qui respire

Un dégradé radial s'étend et se rétracte sur ~7 secondes (inspiration 3 s, expiration 4 s — le rythme de la cohérence cardiaque), dans le hero et, en écho discret, dans le pied de page. Coupé si prefers-reduced-motion.

Pas trop carré

Rayons 24–34 px, vagues SVG entre sections, blob organique pour le portrait.

Le lecteur d'abord

Les cartes d'entrée citent le visiteur (« Tout me stresse… »), pas le métier.

Une action par écran

Prendre rendez-vous — tout le reste est secondaire, y compris dans le menu.

De l'air

Sections en clamp(84–150 px), mesures courtes (36 em), typographie qui respire.

Stack technique

Statique, rapide, sans dépendance au runtime

Le site est compilé en HTML pur : rien à maintenir côté serveur, hébergement minimal, performances par construction.

TechnologieVersionRôle
1Astro5.18Générateur statique — 9 pages HTML, zéro JavaScript obligatoire au chargement
2GSAP + ScrollTrigger3.13Reveals à l'entrée des sections — chargé en différé, jamais dans le chemin critique
3Lenis1.3Défilement adouci (desktop), même politique de chargement différé
4Fontsource5.2Fraunces & Hanken Grotesk auto-hébergées — pas de requête vers Google Fonts
5Docker → nginx:alpine—Build multi-étages, fichiers servis par nginx, cache immuable sur les assets hashés
6Coolify—Déploiement de la maquette sur *.chris-ia.com, HTTPS automatique

Animations différées

GSAP et Lenis s'importent à l'idle ou au premier scroll (src/lib/motion.ts). Sans JavaScript, le site est complet : les reveals sont un plus, pas une condition.

Données centralisées

Lieux, horaires, liens de rendez-vous et coordonnées vivent dans src/data/site.ts — une seule source pour les pages, le pied de page et le JSON-LD.

SEO sans danger

Les canonical pointent vers le domaine final : la maquette ne peut pas se faire indexer à la place du site définitif.

Accessibilité de base

Focus visibles, prefers-reduced-motion respecté partout (halo compris), contrastes AA sur les textes, un seul h1 par page.
